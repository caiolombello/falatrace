03 / RETRIEVE

Use it with your AI tools.

The skill guides retrieval with sources and limits. Models and destinations depend on your configuration; a chat subscription does not automatically include API usage.

Current automatic detection coverage: Slack, Zen and Helium, using local microphone or video-use signals. This signal does not identify the calling service. Other browsers and apps still need integration and tests; manual recording uses the configured backend.

The visual workflow was exercised offline with synthetic video and stubbed model transport. Real-model quality and its decision to request images have not been validated.

Data controls

Know what stays.
And where it goes.

A local starting point.

A new configuration selects local processing and disables automatic processing. Whisper.cpp, Ollama and models are installed separately.

Sending data is a choice.

Transcription can use Whisper.cpp, OpenAI or Gemini; summaries can use Ollama or OpenAI. External providers, workers and backups can transmit content. Check the destination and costs before processing. Existing configurations are preserved.

Deletion has a scope.

Local removal does not erase remote copies or data already accepted by a provider. Local deletion invalidates derived memory before changing artifacts.

AI access · included in alpha.5

Authorize your AI, with visible limitsOpen +

Persistent access for your AI, with visible limits.

Alpha.5 includes persistent authorization per recording and recipient, pause, revocation and an optional preview. A separate opt-in permits frames-only access to current and future recordings on this installation for Codex/OpenAI, Claude/Anthropic or Gemini/Google; it does not authorize API analysis or transcript/summary retrieval. Each client connection is configured separately; there is no guaranteed secret filter. Retrieving local frames does not run a model. OpenAI/Google analysis adapters are implemented, with dispatch disabled by default and no live validation.

Visual observations are partial. Durable visual memory remains a proposal, with no storage activated. No recipient or recording is authorized automatically.
