How it works

From call to context, without losing the source.

Every step stays under your control. You choose when to record, where to process and what to share.

01Record

Records the calls you choose.

Turn on rules to record when Slack, Zoom, Chromium, Firefox, Zen, Helium and other apps use the microphone or camera — or start capture manually. Recording state is always visible.

  • Detection stays off until you enable it; the initial mode only notifies.
  • “Pause new recordings” and “Stop” are separate actions.
  • Microphone and system audio on separate tracks; screen via OBS or GPU Screen Recorder.

02Check

Summaries that point to the source.

Follow each decision back to the transcript segment and the moment in the video. Approximate timing and uncertain references are flagged for review.

  • References carry the segment, the timestamp and the recording’s SHA-256 hash.
  • Transcription with Whisper.cpp on your computer, or OpenAI and Gemini if you configure them.
  • Validation proves the reference exists — not that the model interpreted it correctly.

03Review New in alpha.11

Review without erasing the original.

Fix segments and speaker names in the Studio, generate a new summary with your consent and export exactly the version you checked.

  • History with undo; the original media, transcript and speakers are preserved.
  • A new local summary runs only after you see the model, destination and limits — and confirm.
  • Export to JSON, Markdown, SRT or WebVTT from the preview you reviewed.

For your AI

Context with a source for your agents.

Agents running on your computer — like Claude Code, Codex and Gemini CLI — query your recordings through the CLI or a local MCP server. They receive bounded excerpts with a timestamp, source and hash, and only within what you authorized.

  • Ready-made skill

    Teaches the agent to search, cite the source and respect limits — with no permission to record, upload or delete.

  • Access you control

    Grants per recording and recipient, with pause, revocation and a budget that doesn’t reset on restart.

  • Data, not orders

    Meeting content arrives labeled as untrusted data, never as instructions for the agent.

No agent is connected automatically: you configure each client. Agents backed by cloud models may send what they receive to their provider.

Privacy and control

Your data stays where you decide.

There’s no account and no hosted service: processing happens on your computer or at the destinations you configure.

  • Local by default

    A new configuration uses Whisper.cpp and Ollama on your computer, with automatic processing turned off. You install the models.

  • Sending is your choice

    OpenAI, Gemini, remote workers and backups only run if you configure them — and they can transmit content. Check destination and cost first.

  • Consent at every step

    Recording, generating a Studio summary and releasing frames to an agent are separate authorizations, with limits that persist.

  • Deletion with a clear scope

    Local removal invalidates derived memory before touching files. Remote copies, or data already accepted by a provider, are not erased by it.

Honest status

Used in the author’s routine. Still an alpha.

Caio Barbieri created FalaTrace and continuously uses its recording and context-recovery core. That report is not a reliability measurement — here is what has been verified and what remains to be demonstrated.

Verified offline

  • 759 tests with no failures in the approved alpha.11 candidate, using synthetic data.
  • Locked installation, configuration that doesn’t overwrite yours and uninstall that preserves data.
  • The Studio summary journey passed 8 of 8 cases with real QML in offscreen Qt.

Not yet demonstrated

  • Detection and capture in other browsers, apps and Linux environments.
  • Real-world quality of transcription, speakers, summaries and visual analysis with installed models.
  • Screen readers, varied display scaling, installing on a machine without a package cache, binaries and other platforms.

Start from source

Install alpha.11 in a few commands.

The alpha ships as source code for Linux. None of these commands starts a recording: automation is enabled separately, after you review rules and consent.

You’ll need

  • Linux with Bun 1.4 and FFmpeg
  • Optional: Whisper.cpp and Ollama for local processing
  • Optional: the Qt 6 SDK for the Studio, via bun run desktop:setup
  • Download source code (.tar.gz)
  • Check SHA-256
  • Install the skill in your agents ↗
  • Full guide in the README ↗
Terminal
# 1. Get the code and pin alpha.11
git clone https://github.com/caiolombello/falatrace.git
cd falatrace
git switch --detach v0.2.0-alpha.11

# 2. Install the CLI into ~/.local/bin
bun install --frozen-lockfile --ignore-scripts
make install-cli INSTALL_PREFIX="$HOME/.local"

# 3. Create a config and check your setup (records nothing)
falatrace init
falatrace record doctor

init only creates a config when none exists; existing configurations are preserved. record doctor only inspects the backends.

FAQ

Frequently asked questions

Didn’t find your answer? Open an issue — without pasting configuration or private data.

Does FalaTrace start recording on its own after installation?

No. Installing and running falatrace init doesn’t start any capture. Automatic detection ships turned off; when enabled, its initial mode only notifies. Recording automatically requires an explicit configuration on your part.

Which calling apps does it recognize?

In alpha.11, Slack, Zen and Helium, via local microphone or camera signals — Zoom web, Meet and Teams web in those browsers are recorded too. The main source (next release) adds native Zoom, Teams for Linux, Chromium, Chrome, Brave, Edge, Vivaldi, Opera and Firefox; Discord, Signal, Telegram and Element can be turned on individually. That signal doesn’t identify the service (Meet, Teams, Zoom on the web) or the tab. For other apps, use manual recording.

Do my recordings go to the cloud?

Only if you configure it. A new configuration processes locally with Whisper.cpp and Ollama. Providers like OpenAI and Gemini, remote workers and backups are optional and can transmit content; the Studio shows destination and limits before asking for your consent to summarize.

How much does it cost?

FalaTrace is free and open source (MIT). External providers bill separately, and a chat subscription (ChatGPT, Claude, Gemini) doesn’t include API usage.

Does it work with ChatGPT, Claude or Gemini in the browser?

Not directly. The integration is for agents that run on your computer and use the CLI or the local MCP server, like Claude Code, Codex and Gemini CLI. Hosted websites can’t reach local tools through it.

Can I trust the summaries?

Always check. Summaries point to transcript segments and flag approximate timing and uncertain references. Validation proves the reference exists — not that the model interpreted it correctly.

What about consent from other people on the call?

That’s the responsibility of whoever records. The Studio asks for confirmation before starting a capture, and automatic detection doesn’t establish consent. Follow the laws and policies that apply to you.

Is there a Windows or macOS version?

No. This alpha is Linux-only and distributed as source code.

Is the interface available in English?

The Studio interface is currently in Portuguese. The CLI, the agent skill and the technical documentation are in English.
