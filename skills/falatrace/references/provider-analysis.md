# Separate provider analysis — alpha.5

The production code implements OpenAI Responses and Google generateContent adapters; alpha.5 includes these adapters with API dispatch disabled by default. Tests use generated video, actual FFmpeg JPEG extraction, registered fixture recordings, and stub transport responses. No provider inference, account/model access or billing behavior was validated.

`agent-context provider-status` reports implementation/runtime availability, official destinations, default limits and installation ledger metadata without reading credentials. `provider-authorize --recordings UUID --provider openai|google --model MODEL --options-json JSON --vision-json-declared --consent [--context]` creates a separate persistent grant. The JSON contains explicit maxRequests, maxContextCharacters, maxOutputTokens, timeoutMs, estimatedBudgetUsd (nullable), acceptUnknownCost and rates (inputUsdPerMillion/outputUsdPerMillion/imageInputTokens nullable, source, asOf nullable). No default model or tariff is invented. Studio offers the same production bridge contract and clearly labels manually declared vision/JSON support as unverified. A retrieval-only agent grant never permits API inference.

`analyze-context --grant UUID --recording UUID --request UUID --question TEXT --timestamps SECONDS[,SECONDS]` uses that grant only. The default runtime returns disabled before reading credentials/media or sending a request. A future explicitly authorized runtime can use the existing environment credential interfaces OPENAI_API_KEY/GEMINI_API_KEY; no new persistent key settings were added. The guard is FALATRACE_VISUAL_API_ENABLED=1 and rejects QA-isolated dispatch. Never set it automatically. Missing keys, unsupported models or unknown access are not promises of availability.

When enabled and authorized, selected JPEG bytes, hashes, verified decoded timestamps and optional bounded existing context are the only recording data sent. Responses must use known frame indices/hashes and explicit uncertainty. Recording/media hashes and temporal references are derived locally, not trusted from the model. Output is partial visual observations or abstention; it does not overwrite/regenerate the full existing summary. MCP remains local retrieval-only; this slice does not add an API tool to the agent's retrieval transport.

Counters/attempt receipts persist under the canonical recording-cli visual-review state for this user installation. Restart, cache expiry, another grant or a different request UUID does not reset inference counts. Per-grant request limits coexist with installation lifetime limits and a cumulative known-cost estimate. Unknown tariffs stay unknown and require an explicit choice; a finite estimated USD ceiling refuses unknown-cost history. Estimates use configured metadata, rough text characters/3, image token estimate and output cap; they are neither exact billed tokens nor a provider-side monetary hard cap. Other applications/accounts/installations are outside this ledger. A local owner can delete/edit state; it is not an adversarial billing enforcement system.

Timeout/cancellation after dispatch is uncertain, consumes a receipt and must not automatically retry. Repeating the same ID/input returns cached state, not a second send; changed input/model/grant must not reuse the ID. Expired result cache is removed lazily while attempt receipts remain. Revoke/pause blocks future delivery; it cannot recall data already accepted by a provider. Image/transcript/prompt text and model output are untrusted data, rendered as plain text; instruction separation and strict schemas do not prove model resistance to prompt injection.

Protocol references: [OpenAI image input](https://developers.openai.com/api/docs/guides/images-vision), [Google generateContent](https://ai.google.dev/api/generate-content). Validate current selected-model support and real tariffs separately before any real dispatch. No paid API call is part of this review.
