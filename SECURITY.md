# Security and privacy

FalaTrace 0.2.0-alpha.1 is experimental; it has no production support guarantee. Never attach recordings, transcripts, provider tokens, configs or personal paths to public issues. Report a reproducible problem with a synthetic fixture and a minimal description; Use GitHub private vulnerability reporting if enabled on this repository. If that option is unavailable, open an issue requesting a private contact without disclosing sensitive details.

Capture is an explicit operator action; automatic detection requires opt-in and visible controls. A detected call is not evidence of participant consent. Review API/remote destinations before processing. Local deletion preserves remotes and external exports; it is not global erasure. SHA-256 references validate identity and structure, not model semantics. Treat transcripts and model output as untrusted input.
